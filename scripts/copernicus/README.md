# copernicus

In this folder are the scripts used to download data from the Copernicus database as well as merge those data.

## Scripts

- [fetch_CMEMS.py](./fetch_CMEMS.py): This script is used to download datasets from the copernicus database. It uses the copernicusmarine python librairy.
- [merge_glorys.py](./merge_glorys.py): This script was used to merge glorys datasets but will not work now as the glorys data is not anymore on the cluster.
