\chapter{Modélisation des incertitudes}

Les incertitudes doivent être modélisées explicitement au sein du code \textbf{CROCO}. Pour cela, les travaux de \oldcite{brankart_generic_2015} sur le modèle \textbf{NEMO} servent de base de développement. Dans ce chapitre, nous décrivons tout d’abord les processus stochastiques utilisés, avant de détailler leur implémentation dans le modèle.

\section{Processus stochastiques}

\subsection{Génération des distributions}

Les processus stochastiques implémentés sont des processus autorégressifs gaussiens $\xi^{(i)}$, générés en chaque point de grille $i = 1, \ldots, m$ selon l’équation~\autoref{eq:autoregressive process} :

\begin{equation}
	\label{eq:autoregressive process}
	\xi_{k+1}^{(i)} = a^{(i)} \xi_{k}^{(i)} + b^{(i)} w^{(i)} + c^{(i)}
\end{equation}

où les coefficients $a^{(i)}$, $b^{(i)}$ et $c^{(i)}$ définissent la moyenne souhaitée $\left(\mu^{(i)}\right)$, l’écart-type $\left(\sigma^{(i)}\right)$ et le temps de corrélation $\left(\tau^{(i)}\right)$ de $\xi^{(i)}$.
\begin{figure}[h]
\centering
\includegraphics[width=0.7\textwidth]{Figures/sto_dist_lap_spatial}
\caption{Distribution spatiale du processus stochastique pour un membre}
\label{fig:sto spatial}
\end{figure}

Une corrélation spatiale est ensuite introduite à l’aide d’un filtre laplacien horizontal appliqué à plusieurs reprises. Cette opération permet de générer des structures corrélées dans l’espace et dans le temps, dont l’échelle spatiale est compatible avec celle des phénomènes méso-échelles, comme illustré en \autoref{fig:sto spatial}.

Après une centaine d’itérations du filtre laplacien, on obtient une distribution présentant une corrélation spatiale significative, avec des structures de taille comparable aux tourbillons méso-échelles.
\begin{figure}[h]
\centering
\includegraphics[width=0.7\textwidth]{Figures/sto_dist_lap_dist}
\caption{Distribution marginale du processus stochastique pour un membre}
\label{fig:sto dist}
\end{figure}


Il est néanmoins essentiel de vérifier que la distribution obtenue est bien centrée autour de 1, afin d’éviter l’introduction d’un biais systématique, qu’il soit positif ou négatif. Dans le cas représenté en \autoref{fig:sto dist}, la moyenne est de $1{,}00$ et l’écart-type est de $0{,}32$, ce qui valide la propriété recherchée.
\subsection{Modification des équations}

Une fois les distributions stochastiques générées, nous pouvons modifier les équations \autoref{eq:bulk cd} et \autoref{eq:GLS} afin d’y introduire les perturbations aléatoires.

Dans le cas de la perturbation du stress du vent, cette modification a déjà été implémentée préalablement. L’équation devient alors stochastique et prend la forme suivante~:

\begin{equation}
	\label{eq:sto bulk cd}
	\tau_{\text{STO}} = \boldsymbol{\xi}_{\textbf{C\_D}}(i,j) \; \rho \, C_D \, U \, \uu_z
\end{equation}

où $\boldsymbol{\xi}_{\textbf{C\_D}}(i,j)$ est la variable stochastique spatialisée affectant le coefficient de traînée $\mathbf{C_D}$ à chaque point de grille.

La perturbation du schéma de paramétrisation verticale de l’énergie cinétique turbulente (TKE) a nécessité un travail plus approfondi. Une revue bibliographique a été menée pour identifier des travaux antérieurs portant sur ce type de perturbation. Les travaux de \oldcite{juricke_stochastic_2017} ont étudié l’impact de perturbations stochastiques appliquées à différentes paramétrisations du mélange vertical dans un modèle océanique global à résolution $1^{\circ}$. Leur modèle utilisait une équation prognostique de la \textbf{TKE} similaire à celle donnée en \autoref{eq:tke prog}, ce qui rend leur démarche transposable au modèle \textbf{$k$–$\varepsilon$} utilisé ici.

Ainsi, l’équation du modèle \textbf{GLS} devient :

\begin{subequations}
\label{eq:sto GLS}
\begin{align}
	\pd{k}{t} & = \pd{}{z} \left( K_k \pd{k}{z} \right) + \boldsymbol{\xi}_{\textbf{P}}(i,j) \; P + \boldsymbol{\xi}_{\textbf{B}}(i,j) \; B - \varepsilon \\
	\pd{\varepsilon}{t} & = \pd{}{z} \left( K_\varepsilon \pd{\varepsilon}{z} \right) + \varepsilon k^{-1} \left( \beta_1 \; \boldsymbol{\xi}_{\textbf{P}}(i,j) \; P + \boldsymbol{\xi}_{\textbf{B}}(i,j) \; B - \beta_2 \varepsilon \right)
\end{align}
\end{subequations}

où $\boldsymbol{\xi}_{\textbf{P}}(i,j)$ et $\boldsymbol{\xi}_{\textbf{B}}(i,j)$ sont respectivement les perturbations stochastiques affectant les termes de production dynamique et de destruction par flottabilité. Ces termes permettent d’introduire de l’incertitude dans la dynamique du mélange vertical tout en conservant la structure physique du modèle.


\section{Implémentation dans \textbf{CROCO}}

Les perturbations stochastiques ont été implémentées explicitement dans le modèle \textbf{CROCO} via un développement dédié. Cette implémentation repose sur l'utilisation du module \textbf{STOGEN}, conçu pour générer des champs de variables aléatoires spatialement et temporellement corrélés, et les injecter dans le modèle à chaque pas de temps.

Le module \textbf{STOGEN} permet de produire des champs stochastiques gaussiens autorégressifs selon les propriétés statistiques définies~: moyenne, écart-type, et temps de corrélation. Ces champs sont ensuite lissés horizontalement à l’aide d’un filtre de type Laplacien, afin de faire émerger des structures spatiales réalistes, d’une taille comparable à celle des phénomènes méso-échelles. L'utilisateur peut ajuster le nombre d'itérations du filtre pour contrôler la longueur de corrélation spatiale du bruit.

Une attention particulière a été portée à la neutralité des perturbations vis-à-vis de la moyenne. En effet, pour éviter l’introduction d’un biais systématique dans les simulations, les champs sont centrés autour de $1$ avant injection, comme illustré en \autoref{fig:sto spatial}.

L’injection des perturbations stochastiques se fait à différents endroits du code source :

\begin{itemize}
    \item Pour le stress du vent, le champ stochastique $\boldsymbol{\xi}_{\mathbf{C_D}}$ est appliqué directement dans la formulation du module de forçage de surface, en modifiant le calcul du coefficient de traînée $\mathbf{C_D}$.
    
    \item Pour la paramétrisation du mélange vertical, les champs $\boldsymbol{\xi}_{\textbf{P}}$ et $\boldsymbol{\xi}_{\textbf{B}}$ sont introduits dans les termes sources de l'équation de \textbf{TKE} et de sa dissipation $\varepsilon$, dans le module correspondant à la fermeture turbulente \textbf{GLS}.
\end{itemize}

L’ensemble de cette infrastructure a été conçue de manière modulaire, ce qui permet une activation sélective des perturbations via des options de compilation ou des variables de configuration dans le fichier \texttt{cppdefs.h}. Cela facilite l’exécution de multiples membres d’ensemble avec différentes combinaisons d’incertitudes, tout en conservant une base de code commune.

Cette approche permet de représenter de manière explicite les sources d’incertitude du modèle et d’analyser leur impact sur la dispersion des variables simulées, dans un cadre cohérent et contrôlé.
